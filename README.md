# Package [cloudeng.io/tui/tview](https://pkg.go.dev/cloudeng.io/tui/tview?tab=doc)

```go
import cloudeng.io/tui/tview
```

Package tview provides rivo/tview utilities and struct-driven TUI editors:

  - cloudeng.io/tui/tview/structtag: parses yaml and tview struct tags.
  - cloudeng.io/tui/tview/structmodel: cyclic-safe reflection schemas,
    uniform ValueRef bindings, codecs, and lazy tree nodes.
  - cloudeng.io/tui/tview/structedit: split-view rivo/tview settings editor.
